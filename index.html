Dev 21 Ltd builds SatStack, an open-source Bitcoin portfolio application. Purchases, sales, and preferences stay on the phone. There is no account and no remote copy of the portfolio.

Get SatStack on Google Play Source on GitHub

SatStack

  • Record Bitcoin purchases and sales
  • Live prices via CoinGecko. Only price requests leave the device; holdings are not sent
  • Value, cost basis, and return in USD, GBP, EUR, CAD, AUD, JPY, or CNY
  • Charts with trade markers and pinch-zoom
  • Optional PIN wraps on-device storage. JSON backups use a separate password
  • CSV and PDF reports are unencrypted files — treat them as financial records

SatStack is a record-keeping tool. It is not investment advice and it does not custody Bitcoin or private keys. Android is the supported platform. Contact: open an issue on the SatStack repository.
